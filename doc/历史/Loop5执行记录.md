## 目标

将工具箱的搜索与可发现性从“能用”推进到可检查、可回归和可维护的状态。

## 已完成内容

### 搜索体验

- 增加 `cat:` 和 `tag:` 搜索语法。
- 增加 `cat:*`、`tag:*` 快捷提示。
- 支持分类部分匹配、普通关键字组合和逗号分词。
- 在搜索结果卡片展示命中原因。
- 增加清空按钮、无结果说明和重试入口。
- 固定评分加名称的排序规则，切换主题不会改变结果顺序。

### 元数据质量

- 新增 `scripts/check-tools-metadata.mjs`。
- 检查工具必填字段、空关键字和空标签。
- 检查重复工具 ID、路径、关键字和标签。
- 将检查命令注册为 `npm run check:tools`。

### 自动回归

- 新增搜索冒烟脚本，覆盖分类、标签、大小写、特殊符号和空查询。
- 新增界面结构检查，覆盖搜索提示、清空操作和无结果入口。
- 新增主题顺序检查，防止主题状态影响搜索排序。
- 新增兼容性检查，覆盖 SPA 回退、别名路由和 `.nojekyll`。
- 将全部检查整合到 `npm run qa:loop5`。

### 缺陷修复

- 修复搜索冒烟脚本在排序后丢失命中原因的问题。
- 增加未知分类、未知标签和裸前缀场景。
- 增加 `/`、`+`、`*` 等特殊符号的稳定性场景。
