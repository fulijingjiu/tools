# 功能测试文档

> 适用版本：当前开发版本  
> 测试目标：确认工具箱的主要功能可用，并保证桌面端、移动端及深浅主题下的界面清晰、舒适。

## 使用方式

1. 执行 `npm run dev` 并在浏览器打开本地地址。
2. 每项测试完成后，在“结果”栏填写“通过 / 不通过 / 待确认”。
3. 若不通过，记录复现步骤和截图即可；不要求编写复杂测试报告。

## 视觉验收标准

- 页面层级清楚：标题、说明、输入区、操作按钮和结果区易于区分。
- 关键操作有明显按钮状态；悬停、聚焦和禁用状态可辨识。
- 长文本、错误信息和结果内容不会压住按钮或超出容器。
- 深色、浅色主题均保持足够对比度；图片预览和二维码边缘清晰。
- 手机端不出现横向滚动；输入、复制、下载等常用操作方便点击。
